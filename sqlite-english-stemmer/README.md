# sqlite-english-stemmer

![Crates.io License](https://img.shields.io/crates/l/sqlite-simple-tokenizer)

## 简介

这个项目提供一个适用于英语的词干提取器和一些将英语单词归一化的方法，还有一个判断特殊字符的方法。
